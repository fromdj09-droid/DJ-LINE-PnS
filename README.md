# DJ LINE PnS

Windows용 데스크톱 Excel에서 사용하는 건설 공정관리 프로그램의 설치·업데이트 배포 저장소입니다.

[최신 설치 파일 다운로드](https://github.com/fromdj09-droid/DJ-LINE-PnS/releases/latest/download/DJ-LINE-PnS-Setup.exe) · [버전별 배포 내역](https://github.com/fromdj09-droid/DJ-LINE-PnS/releases)

## 설치

1. Excel 문서를 저장하고 Excel을 모두 닫습니다.
2. 설치 파일을 실행해 설치합니다.
3. Excel을 열고 **DJ LINE PnS → 시작**에서 새 공정 파일을 만듭니다.

웹용·모바일 Excel에서는 VBA 기능을 사용할 수 없습니다. 매크로가 조직의 보안 정책으로 차단되면 해당 정책에 따라 처리해 주세요.

## 업데이트

처음 설치하면 GitHub 업데이트 주소가 기본 설정됩니다. Excel 시작 시 새 버전을 확인하고, 배포 서명과 파일 검사를 통과한 업데이트만 적용합니다. 연결이나 검증에 실패하면 기존 버전을 유지합니다. 작성한 현장 공정 파일은 업데이트 대상에 포함되지 않습니다.

이전 설치의 주소나 비활성 상태는 보존됩니다. 기존 사용자는 **DJ LINE PnS → 관리 → 업데이트 설정**에서 아래 주소를 한 번 확인해 주세요.

https://github.com/fromdj09-droid/DJ-LINE-PnS/releases/latest/download/manifest.json

공정 계산·입력창·기본 양식은 자동 업데이트됩니다. 리본 실행기나 업데이트 실행기 자체를 교체해야 하는 버전은 새 설치 파일을 실행해야 합니다.

## 계정과 자료 보호

- 설치·업데이트를 받는 사용자는 GitHub에 로그인하거나 비밀번호·토큰을 입력할 필요가 없습니다.
- 설치 파일, 서명된 업데이트 파일과 안내문만 게시합니다. 개발 원본 파일, 실제 현장 공정 자료, 백업과 비밀 서명키는 게시하지 않습니다.
- 배포 파일에는 실행에 필요한 VBA가 포함됩니다. VBA 프로젝트 잠금은 코드 암호화를 보장하지 않습니다.
- 프로그램은 Office 보안 설정을 자동으로 변경하지 않습니다.
- 오류 제보 시에는 비밀번호·인증코드·토큰과 실제 현장 자료를 제외해 주세요.
